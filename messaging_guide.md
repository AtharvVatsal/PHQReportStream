# IRBn Daily Message Writing Guide

---

## Get Started. Do it Right. Save Everyone Time.

*Prepared for all Battalion COs / Staff sending daily WhatsApp reports.*

---

## 1. Why This Matters

Your daily messages are parsed automatically by the HP Police ReportStream tool. When the format is consistent:
- ✅ Reports are generated **instantly**
- ✅ Data is **accurate** and **searchable**
- ✅ Saves **manual correction time**

---

## 2. The Golden Rules

1. **Do NOT change** the headings or numbering (1-11)
2. Always put a **colon (:)** after each heading
3. Use **Nil** (capital N) when there is nothing to report
4. **Dates**: Use `DD.MM.YYYY` format (e.g., `21.07.2025`)
5. **Districts**: Only use district names in Section 2
6. **No emojis** or decorative symbols
7. Use **plain text** only

---

## 3. The Standard Template

```
Name of IRBn/Bn: <Full name & location>

1. Reserves Deployed: <Yes/No or details>
2. Districts where force deployed: <Distt1, Distt2>
3. Stay Arrangement/Bathrooms: <Good/Average/Poor>
4. Messing: <Good/Average/Poor>
5. CO's last Interaction with SP: <DD.MM.YYYY>
6. Disciplinary Issues: <Nil or details>
7. Reserves Detained: <Nil or details>
8. Training: <Nil or details>
9. Welfare: <Nil or details>
10. Reserves Available: <Yes/No or number>
11. Issue for PHQ: <Nil or details>
```

## 5. Complete Example

### ✓ CORRECT FORMAT

```
Name of IRBn/Bn: 1st HPAP BN Junga, Shimla

1. Reserves Deployed: Yes
2. Districts where force deployed: Shimla, Kangra
3. Stay Arrangement/Bathrooms: Good
4. Messing: Good
5. CO's last Interaction with SP: 05.04.2026
6. Disciplinary Issues: Nil
7. Reserves Detained: Nil
8. Training: Nil
9. Welfare: Nil
10. Reserves Available: Yes
11. Issue for PHQ: Nil
```

### ✗ WRONG FORMAT

```
1st HPAP BN Junga
Reserves: Yes
Districts: Shimla (25 force)
Stay: good 👍
Messing: available
CO Date: 5th April
Disciplinary: none
Training: going on
Welfare: CSR
Reserves: few
Issues: no issue
```

## 7. Tips for Success

✅ **DO:**
- Use the exact template above
- Write "Nil" (capital N) for empty fields
- Use DD.MM.YYYY date format
- Use simple, clear text

❌ **DON'T:**
- Use emojis or symbols
- Use "None", "NA", "-" for empty
- Skip numbering
- Use long paragraphs
- Add extra headings
